# stada 📚 — پلتفرم هوشمند برنامه‌ریزی، گزارش مطالعه و تحلیل آزمون

**stada** یک پلتفرم جامع فارسی (راست‌به‌چپ) برای دانش‌آموزان کنکور سراسری (تجربی، ریاضی، انسانی، هنر، زبان)، داوطلبان کارشناسی ارشد و دکتری و سایر آزمون‌های تخصصی است که با **Next.js (App Router + TypeScript)**، **Tailwind CSS v4**، **Chart.js** و **Supabase PostgreSQL** ساخته شده و روی **Vercel** مستقر شده است.

## امکانات کلیدی (نسخه ۳)

- **پروفایل شخصی، انتخاب رشته و مدیریت دروس (`⚙️ تنظیمات`)**:
  - پشتیبانی از کنکور سراسری تمامی رشته‌ها، ارشد زیست‌شناسی و آزمون‌های سفارشی
  - تعریف بی‌نهایت درس دلخواه به همراه آیکون و **انتخاب رنگ اختصاصی هر درس** (با پالت رنگی + Color Picker کامل)
  - تنظیم تاریخ آزمون هدف با شمارش معکوس روزشمار و نمایش معادل شمسی
- **ثبت یکپارچه گزارش مطالعه و تست (`📝 ثبت گزارش`)**:
  - ثبت همزمان تاریخ، درس، مبحث مطالعه‌شده، ساعت و دقیقه مطالعه
  - ثبت نام منبع/کتاب، شماره شروع و پایان صفحات (`از صفحه X تا صفحه Y`) و محاسبه خودکار تعداد صفحات
  - ثبت یکپارچه تعداد کل تست، غلط و نزده با محاسبه زنده دقت (`%`) و درصد کنکوری با نمره منفی یک‌سوم
- **برنامه‌ریزی هفته پیش رو (`📅 برنامه هفتگی`)**:
  - تعریف باکس‌های مطالعاتی ساعتی برای شنبه تا جمعه هفته جاری و هفته آینده (مثلاً: *زیست سلولی و مولکولی — غشا بخش ۱ — ساعت ۰۹:۰۰ تا ۱۱:۰۰ روز شنبه*)
  - پیگیری تحقق برنامه هفتگی و تبدیل یک‌کلیکی هر باکس برنامه به گزارش مطالعه
- **تایمر پومودورو استاندارد (`⏱️ پومودورو`)**:
  - زمان‌های پیش‌فرض مطالعه: **۲۵، ۴۵ و ۹۰ دقیقه**
  - زمان‌های پیش‌فرض استراحت: **۵، ۱۵ و ۳۰ دقیقه**
  - حلقه تایمر با رنگ اختصاصی درس انتخاب‌شده، زنگ صوتی Web Audio و ثبت مستقیم مبحث/صفحات/تست
- **گزارش‌ها و نمودارهای رنگی ۴گانه (`📊 گزارش‌ها`)**:
  - مشاهده کارنامه تحلیلی به صورت **روزانه**، **هفتگی**، **ماهانه** و **کلی**
  - نمودارهای میله‌ای پشته‌ای و دایره‌ای با **رنگ تعریف‌شده هر درس** تا سهم مطالعه هر درس کاملاً تفکیک‌شده باشد + خروجی CSV
- **جدول رتبه‌بندی هفتگی و پنل کلاس دبیر/مشاور (`🏆 رتبه‌بندی` / `🏫 پنل کلاس`)**:
  - ساخت کلاس با کد دعوت اختصاصی و پایش لحظه‌ای ساعت مطالعه، صفحات، تست‌زنی و استریک دانش‌آموزان

## راه‌اندازی محلی

```bash
npm install
npm run dev
```

در محیط توسعه در صورت عدم تنظیم متغیرهای `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY`، داده‌ها به صورت خودکار در فایل محلی `.cache/stada-dev.json` ذخیره می‌شوند تا تست کامل بدون نیاز به اتصال ابری ممکن باشد.

## متغیرهای محیطی (Vercel / Production)

| متغیر | توضیح |
| --- | --- |
| `SUPABASE_URL` | آدرس پروژه Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | کلید Service Role سرور Supabase |
| `AUTH_SECRET` | کلید امضای توکن احراز هویت (`HS256`) |
| `EXAM_DATE` | تاریخ پیش‌فرض آزمون هدف (`YYYY-MM-DD`) |
