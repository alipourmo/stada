# 🧬 BioTrack (stada) — داشبورد هوشمند کنکور زیست‌شناسی

پلتفرم تحت وب ویژه داوطلبان کنکور زیست‌شناسی برای مدیریت زمان مطالعه، تایمر پومودورو، ثبت و تحلیل تست‌ها (با محاسبه درصد کنکوری نمره منفی) و رقابت گروهی با همکلاسی‌ها؛ بازنویسی‌شده با **Next.js (App Router + TypeScript)** و پایگاه داده **Supabase PostgreSQL**.

## ✨ امکانات کلیدی (Features)

- **🔐 احراز هویت سریع و امن:** ثبت‌نام و ورود با ایمیل و رمز عبور (نشست ۳۰ روزه با کوکی امن `HttpOnly` JWT) و امکان ساخت یا پیوستن به کلاس همزمان با ثبت‌نام.
- **📊 داشبورد جامع:**
  - نمایش آمار کل مطالعه، مطالعه امروز، دقت کلی تست‌ها، روزهای پیوسته مطالعه (`Streak 🔥`) و رتبه در کلاس.
  - شمارش معکوس تا کنکور (روز، هفته، ماه) به همراه امکان شخصی‌سازی تاریخ آزمون هدف و هدف ساعت مطالعه (پیش‌فرض: ۵۰۰ ساعت).
  - نمودار میله‌ای مطالعه ۷ روز اخیر و نمودار خطی روند دقت تست‌ها.
  - تفکیک زمان مطالعه در ۶ درس تخصصی: **زیست سلولی 🔬، زیست مولکولی 🧬، ژنتیک 🧫، بیوشیمی ⚗️، زبان تخصصی 📖 و سایر 📚**.
- **⏱️ تایمر پومودورو دقیق:**
  - تایمر دایره‌ای با دقت زمانی واقعی (Wall-Clock) مقاوم در برابر پس‌زمینه شدن مرورگر.
  - حالت‌های مطالعه (۲۵، ۴۵، ۵۰ دقیقه) و استراحت (۵، ۱۵ دقیقه)، زنگ هشدار صوتی پایان دور، ذخیره زمان مطالعه ناتمام و امکان **ثبت دستی مطالعه**.
  - بروزرسانی خودکار `Streak` روزانه بر اساس منطقه زمانی `Asia/Tehran`.
- **📝 ثبت و تحلیل تست:**
  - پیش‌نمایش زنده **دقت پاسخگویی** و **درصد کنکوری (با احتساب نمره منفی یک‌سوم)** بر اساس تعداد کل سوال، غلط و نزده.
  - ثبت یادداشت برای هر آزمون و فیلتر تاریخچه تست‌ها بر اساس درس.
- **🏆 کلاس و لیدربورد رقابتی:**
  - ساخت کلاس با کد ۶ کاراکتری یکتا (با دکمه کپی سریع) و پیوستن یا خروج از کلاس.
  - رتبه‌بندی اعضای کلاس بر اساس ۴ معیار: **امتیاز کل** (`ساعت مطالعه × ۱۰ + استریک × ۵ + تعداد تست × ۲`)، **ساعت مطالعه**، **تعداد تست** و **Streak**.
- **📈 گزارش پیشرفت و مشاور هوشمند:**
  - نمودار راداری (Radar) تسلط به دروس، میانگین روزانه ۳۰ روز اخیر، تحلیل دقت تست به تفکیک هر درس و سیستم **پیشنهاد هوشمند** برای شناسایی نقاط ضعف و دروس کم‌مطالعه‌شده.
- **📱 طراحی کاملاً واکنش‌گرا (RTL):** فونت فارسی **وزیرمتن (Vazirmatn)** توکار بدون وابستگی به CDN خارجی + منوی پایین صفحه اختصاصی موبایل.

## 🛠️ راه‌اندازی محلی (Local Development)

```bash
npm install
cp .env.example .env.local
npm run dev
```

> در محیط توسعه محلی اگر متغیرهای `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` تنظیم نشده باشند، برنامه به صورت خودکار از مخزن توسعه محلی (`.cache/biotrack-dev.json`) استفاده می‌کند.

## 🗄️ راه‌اندازی دیتابیس Supabase و دیپلوی Vercel

1. اسکریپت `supabase/schema.sql` را در بخش **SQL Editor** پروژه Supabase اجرا کنید.
2. متغیرهای محیطی زیر را در پروژه Vercel تعریف کنید:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `AUTH_SECRET`
   - `EXAM_DATE` (اختیاری، پیش‌فرض `2027-05-06`)
3. پروژه را با Preset فریم‌ورک **Next.js** روی Vercel دیپلوی کنید.
