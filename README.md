# استادا

استادا یک MVP تک‌کاربره برای مدیریت سال کنکور کارشناسی ارشد زیست/بیوتکنولوژی است. این نسخه برای هاست اشتراکی PHP/MySQL آماده شده و برای اجرا به Node.js، Composer یا SSH روی هاست نیاز ندارد.

## مشخصات پیشنهادی هاست

- دامنه/ساب‌دامین: `s.alirezapourmohammadi.ir`
- PHP: نسخه 8.2
- MySQL: فعال
- افزونه‌ها: `pdo_mysql`, `curl`, `openssl`, `mbstring`, `json`

## نصب

1. محتوای پوشه `public_html` را داخل Document Root ساب‌دامین آپلود کنید.
2. فایل `public_html/config.example.php` را در هاست به `config.php` تغییر نام دهید.
3. اطلاعات دیتابیس و OpenAI API Key را در `config.php` وارد کنید.
4. فایل `public_html/schema.sql` را در phpMyAdmin روی دیتابیس اجرا کنید.
5. سایت را باز کنید و با ایمیل/رمز تنظیم‌شده در `config.php` وارد شوید.

## OpenAI API

اشتراک ChatGPT جای API Key را نمی‌گیرد. باید از داشبورد OpenAI یک API Key جدا بسازید و مقدار آن را فقط در `config.php` سمت سرور قرار دهید.

## امکانات MVP

- داشبورد فارسی و RTL
- شمارش معکوس تا ۱۷ اردیبهشت ۱۴۰۶
- ثبت مطالعه و کیفیت مطالعه
- برنامه روزانه/هفتگی
- مرور فاصله‌دار برای مبحث، فلش‌کارت و خطا
- تایمر پومودورو
- بانک سوال و ورود گروهی متنی
- آزمون مبحثی ساده
- دفترچه خطاها
- فلش‌کارت دستی و تولید پیشنهادی با AI
- چت AI با ذخیره کامل پرسش‌وپاسخ
- چک‌این روزانه
- گزارش‌های پایه و امتیاز آمادگی
